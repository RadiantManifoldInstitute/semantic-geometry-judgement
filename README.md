# Can Semantic Geometry Teach an AI Judgement?

Scientific evidence and replication companion for the paper by Thomson D. Nguy,
Radiant Institute for Manifold Studies.

## Preparation status

This repository is private staging. It currently contains this preparation
README only. No scientific package has been released, and no replication claim
is made by the existence of the repository.

The companion will cover the four frozen studies:

1. Compact representation and relation recovery.
2. Proximity, direction, and consequence measurements.
3. Composed routing and action decisions.
4. Separating policy retrieval, relation interpretation, and action disposition.

Each study package is intended to contain its protocol and analysis criteria,
synthetic data and labels, frozen splits, evaluation code, model and environment
pins, complete reported results, and reproduction instructions. A claim-to-artifact
index will connect the paper's numbers, figures, and tables to the supporting
files and calculations.

## Verification levels

Recomputing reported quantities from frozen outputs and rerunning the experiments
from their original inputs are separate checks. Neither a repository listing nor
a successful setup test establishes full replication.

Null and unfavorable findings, comparator outcomes, denominators, exclusions, and
limitations must remain visible. The consequence-graph hypothesis is proposed,
not tested by these four studies.

## Public companion boundary

Internal correspondence, administrative approvals, credentials, private
infrastructure and operational records, and held successor material are excluded
from the public companion. Scientific study identifiers and checksums may be
retained for traceability.

No license, public release, immutable scientific release identifier, or paper
availability link has been activated by this initial staging commit. A versioned
scientific candidate must pass exact source, scientific, disclosure, rights, and
release review before it is made public.
